# AcolhePet

Plataforma web desenvolvida para uma ONG de proteção animal.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git

## Funcionalidades

- Navegação SPA
- Cadastro de apoiadores
- Validação de formulários
- Armazenamento com localStorage
- Interface responsiva

## Estrutura do projeto

O projeto está organizado em pastas separadas para HTML, CSS, imagens e JavaScript.
